# Paludarium

A little habitat to build and watch, with plants, frogs and fish.

[Try it](https://turnerburchard.com/paludarium/).

Worlds lists presets and saved habitats. First visits open it automatically;
returning visits resume the saved habitat. The open world autosaves in this
browser, including animal life. Build edits keep a preset in Your worlds,
with recently opened saves first. Switching away discards an unedited preset.

To run locally with Node.js 22 or newer:

```sh
npm ci
npm run dev
```
